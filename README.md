# Wanderlust

Wanderlust is a full-stack web application similar to Airbnb.
Users can sign up, log in, and add, edit or delete travel
listings with images and location.

Live link: https://majorpn1-1.onrender.com

## Features
- User signup and login
- Add, edit and delete listings
- Upload images (Cloudinary)
- Show location on a map (Mapbox)
- Filter listings by category

## Technologies Used
Node.js, Express.js, MongoDB, EJS, HTML, CSS, JavaScript,
Cloudinary, Mapbox

## How to run
1. Download or clone this repository
2. Run: npm install
3. Create a .env file and add your own keys
4. Run: node app.js
